## 容器

把一个应用程序，以及它运行所需要的环境，一起打包起来的“轻量级运行单元”

镜像是一个静态的模版，容器是一个运行时状态实例

虚拟机 = 操作系统 + 应用程序

容器，共享宿主机内核（容器 = 隔离的进程 + 文件系统 + 网络 + 资源限制）

| 对比项 | 虚拟机 | 容器 |
| --- | --- | --- |
| 隔离级别 | 更强 | 较轻量 |
| 启动速度 | 慢，分钟级 | 快，秒级 |
| 资源占用 | 高 | 低 |
| 是否包含完整 OS | 是 | 否 |
| 适合场景 | 多系统隔离 | 应用部署、微服务 |
